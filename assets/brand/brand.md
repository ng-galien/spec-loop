# spec-loop brand

The mark is the agent glyph (a robot head with an antenna) inside an open clockwise loop arrow, whose gap the antenna points into: an agent working in a loop.

- **Files**: `mark.svg` (square mark), `logo.svg` (mark plus the wordmark « spec-loop » in Inter 650), `favicon.svg` (32 px mark). Each one switches to its dark variant through `prefers-color-scheme`.
- **Ink**: slate `#0f172a` (head, wordmark, headings) on light; `#f8fafc` on dark.
- **Greys**: `#334155` body text, `#64748b` secondary text, `#cbd5e1` borders and rules, `#f8fafc` light background, `#0f172a` dark background.
- **Accent**: blue `#2563eb` for the loop, links and the primary action; soft tint `#dbeafe` for highlighted surfaces, and for links and accents on dark backgrounds.
- **Status**: green `#15803d` only for « passing »; red `#b42318` only for « refused ». Never decorative.
- **No warm colour**, ever: no cream, beige, orange, amber, brown or terracotta.
- **Type**: Inter (Google Fonts), falling back to system-ui; monospace for code: ui-monospace, SF Mono, Menlo.
- **Clear space**: keep the height of the head free around the mark; the smallest size is 16 px, which leaves out the wordmark.
- **Do not** recolour the head and loop with the same blue, add gradients or shadows, or rotate the loop.
